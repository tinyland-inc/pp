# prompt-pulse (archived)

This Go static shell dashboard was retired under Tinyland issue `TIN-3350`.
It is preserved as historical source and is no longer a writable product or a
fleet/runtime authority.

`tinyland-inc/lab` removed the package, services, shell startup, cache surfaces,
and current Rust TUI delivery from all managed hosts. Do not reinstall or repin
this repository into Lab.

The separate Rust/waifu TUI remains active at
[`Jesssullivan/prompt-pulse-tui`](https://github.com/Jesssullivan/prompt-pulse-tui)
under `TIN-3094`. Any future Lab delivery requires a new reviewed integration;
it does not inherit this repository's former startup behavior.

## Historical Note

The preserved Go module and Bazel/Gazelle prefix use the retired GitLab path
`gitlab.com/tinyland/lab/prompt-pulse`. Public installation through that path is
not supported. The documentation and source in this repository describe the
retired implementation and must not be treated as current fleet guidance.
